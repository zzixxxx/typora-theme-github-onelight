# 表格样式

> 本页对应主题里的「表格」：mdmdt 的 8px 圆角卡片 + 斑马纹 + 1px 边框，叠加 onelight 的悬停高亮（整行浅色、当前单元格更深）。

## 基础表格

| 功能点 | 来源 | 说明 |
| ------ | ---- | ---- |
| 表格 | mdmdt | 圆角卡片、斑马纹、表头灰底 |
| 悬停高亮 | onelight | 鼠标移到某行整行变浅蓝，当前格更深 |
| 引用块 | onelight | 白色卡片 + 左侧色条 |
| 代码块 | onelight | 白色卡片、行悬停、右下角语言标签 |
| 文本 | mdmdt | 粗体 / 高亮 / 链接图标 / kbd |

| 元素 | 示例 |

## 表格内的复选框

Markdown 表格里写 `- [ ]` 不会变成复选框，Typora 也不渲染 `<input>`（不在它的行内 HTML 白名单里，只会显示源码）。本主题用 `span` 代替：`<span ty-class="cb">&nbsp;</span>` 未勾选、`<span ty-class="cb on">&nbsp;</span>` 已勾选，外观与任务列表复选框一致。

- `class` 属性会被 Typora 过滤掉，`ty-class` 是 Typora 专门放行的替代属性；span 里必须有内容（写 `&nbsp;`），空 span 会连源码一起显示。
- 勾选状态在源码里：点击复选框，Typora 会展开这段 HTML 源码，加 / 删 `on` 后点到别处即生效。
- 单元格里用 `<br>` 分行时会看到灰色 `<br>` 标记，这是 Typora 自己的开关：菜单 `编辑 → 空白字符与换行 → 可见 <br/>`，取消勾选即隐藏。

| 序号 | 事项 | 状态 |
| :--: | ---- | ---- |
| 1 | 已完成的事项 | <span ty-class="cb on">&nbsp;</span> 已做 |
| 2 | 未完成的事项 | <span ty-class="cb">&nbsp;</span> 待做 |
| 3 | 带子项 | <span ty-class="cb on">&nbsp;</span> 子项 A 已完成<br><span ty-class="cb">&nbsp;</span> 子项 B 待做 |
