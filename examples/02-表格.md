# 表格样式

> 本页对应主题里的「表格」：mdmdt 的 8px 圆角卡片 + 斑马纹 + 1px 边框，叠加 onelight 的悬停高亮（整行浅色、当前单元格更深）。

## 基础表格

| 功能点 | 来源 | 说明 |
| ------ | ---- | ---- |
| 表格 | mdmdt | 圆角卡片、斑马纹、表头灰底 |
| 悬停高亮 | onelight | 鼠标移到某行整行变浅蓝，当前格更深 |
| 引用块 | onelight | 白色卡片 + 左侧色条 |
| 代码块 | onelight | 白色卡片、行悬停、右下角语言标签 |
| 文本 | mdmdt | 粗体 / 高亮 / 链接图标 / kbd |

## 对齐方式

| 左对齐 | 居中 | 右对齐 |
| :----- | :--: | -----: |
| 仓库 A | 1,160 | 17,150 |
| 仓库 B | 1,170 | 16,950 |
| 仓库 C | 840 | 20,460 |

## 表格内的行内元素

| 元素 | 示例 |
| ---- | ---- |
| 行内代码 | `SELECT * FROM Wms_DepotCargoLog` |
| 粗体 / 斜体 | **重要** / *备注* |
| 链接 | [zzixxxx](https://github.com/zzixxxx) |
| 高亮 / 删除线 | ==已确认== / ~~作废~~ |
| 键盘键 | <kbd>Ctrl</kbd> + <kbd>S</kbd> |
