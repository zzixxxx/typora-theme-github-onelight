# 代码

行内代码：`npm install`、`--theme-color`。

```csharp
public async Task<int> GetStockAsync(long skuId, long depotId)
{
    // 基本单位整数库存
    var qty = await _db.Stocks
        .Where(s => s.SkuId == skuId && s.DepotId == depotId)
        .SumAsync(s => s.Quantity);
    return qty;
}
```
